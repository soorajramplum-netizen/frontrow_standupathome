Front Row: theme preview

The same home screen and chat in three looks. A is Meta's Astryx Butter theme, which the app uses today. B and C are two themes from Hallmark (Nutlope/hallmark) that suit a comedy app. Any of them can be applied inside Astryx as a custom theme, so the components and code stay the same.

A · Meta Astryx: Butter (current)

Warm butter paper, one blue accent, a script logo. Calm and friendly, so the jokes do the work.

Generated basis my improv lines I recorded & others online. All personas are parodies.
